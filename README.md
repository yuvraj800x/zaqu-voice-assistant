# zaqu-voice-assistant
An AI-powered offline voice assistant built with Python.  Uses Phi-3 AI model via Ollama for intelligent responses  and Speech Recognition for voice input.  Just like Siri but built from scratch! 🤖🎤

## Features
- 🎤 Voice Recognition
- 🤖 AI Powered (Phi-3 Offline)
- 🔊 Text to Speech
- 💬 Hindi + English Support

## Requirements
- Python 3.11
- speechrecognition
- pyttsx3
- ollama

## How to Run
1. Install Ollama
2. Run: ollama pull phi3:mini
3. pip install speechrecognition pyttsx3 ollama
4. python speech_recognition2.py
